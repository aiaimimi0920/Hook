# Otter 使用教程

[English](getting-started.md) · [文档中心](../README.md)

从截取第一张钉图开始，逐步使用编辑、节点和投射。本文对应当前源码；历史发布版可能不包含所有功能。

## 准备与启动

- 使用 Windows 10 或 11，并准备 WebView2 Runtime。
- 从 [Otter Releases](https://github.com/aiaimimi0920/Otter/releases) 下载便携版 ZIP，解压后运行包内程序。当前源码构建使用 `otter.exe`；Hook v0.2.33 等历史包仍使用 `hook.exe`，以对应版本说明为准。
- 本地截图、钉图和编辑不需要 Loom。OCR、翻译和 Loom 能力节点需要另行准备 Loom，并安装、启用和授权对应能力包；启动 Loom 不等于所有能力都已可用。
- 当前没有在此提供经过核验的 Otter + Loom 联合安装包。包格式、签名状态与数据目录见[发布包说明](packages.zh-CN.md)。

## 1. 截取并钉在桌面

1. 启动 Otter，按 **`Ctrl+1`**，框选要截取的区域。
2. 画面生成钉图后，可将其移动到桌面需要的位置，作为参考或继续编辑。
3. **`Ctrl+2`** 用于实时截图，**`Ctrl+3`** 用于长截图；实时截图的源程序兼容性和资源限制见[实时截图说明](../LIVE_CAPTURE.md)。

不支持在 UAC 安全桌面内截图或覆盖钉图。实时截图不保证任意程序的后台输入或固定帧率，详见[安全边界](../SECURITY_BOUNDARIES.md)。

## 2. 编辑与标注

1. 选中钉图，按 **`Ctrl+E`** 显示或隐藏编辑工具栏。
2. 使用文字、箭头、形状、画笔、模糊等工具处理画面；按 **`Ctrl+Z`** 撤销，**`Ctrl+Y`** 重做。
3. 按 **`Tab`** 展开或收起所选钉图的参数面板。
4. 退出编辑或选择状态后，按 **`Esc`** 删除钉图。编辑草稿、截图选择或弹窗仍在活动时，Esc 会优先取消或关闭当前操作；选中标注时，删除操作可能作用于标注。
5. 按 **`Ctrl+S`** 保存所选图像，也可按住 **`Shift`** 将图像拖出到资源管理器。

进一步阅读：[自由笔触](../FREEHAND_EDITING.md) · [贝塞尔曲线](../BEZIER_EDITING.md) · [功能与快捷键](../FEATURES.md)。

## 3. 使用 OCR、翻译与 Art 节点

先启动 Loom，安装并启用所需能力包，完成 Otter 与 Loom 的连接及授权。连接、审批与重新连接的操作见[全局 Loom 连接](../LOOM_CONNECTION.md)。

选中图片钉图后：

| 快捷键 | 操作 |
| --- | --- |
| **`Ctrl+4`** | 使用可用的 OCR 能力重新识别，并复制完整结果。 |
| **`Alt+4`** | 切换 OCR 结果显示；没有结果时先识别并显示。 |
| **`Ctrl+5`** | 翻译已有 OCR 内容；没有 OCR 时先识别。 |
| **`Alt+5`** | 切换翻译结果显示；首次使用时生成所需结果。 |
| **`Shift+1`** | 打开 Art 菜单，再选择可用能力添加节点。 |

在 Otter 的节点工作区中连接节点、组合处理流程；Loom 提供已安装并授权的能力。节点及参数以实际可用能力为准。OCR 和翻译的显示控件互斥，切换已有结果不会重复请求模型。

## 4. 将钉图投射到另一台设备

这里的设备指支持现有投射协议、完成所需连接与授权的 Otter 接收端，不表示任意客户端或所有平台都兼容。先从两台运行 Otter 的 Windows 电脑、同一 Loom 的已配对设备开始：

1. 两端连接同一 Loom，并完成设备配对及批准。接收端需启用接收；默认手动批准新的投送。
2. 发送端选中钉图，按 **`Ctrl+E`** 打开工具栏，在贴图设置下方进入“投射”面板。
3. 打开目标设备或设备组列表，勾选可用目标。接收端根据策略接受或拒绝；发送端收到接收显示回执后才标记成功。
4. 关联建立后，发送端后续编辑会持续同步。取消勾选可停止投射；关闭面板不会自动停止已有同步。

也可使用二维码或链接邀请；接收端从托盘“接收投射”或钉图内的导入入口接收。邀请有效期、跨 Loom 互信、接收策略与双向编辑限制见[图片投射完整说明](../QR_PROJECTION.md)。

## 遇到问题

- OCR、翻译或 Art 不可用：检查 Loom 连接与授权，以及对应能力包是否安装、启用。
- 找不到接收设备：检查两端连接、配对审批和接收策略；“已连接”不代表所有远程业务都已开放。
- 快捷键行为不同：确认当前是否选中钉图、标注或输入框，以及是否仍处于编辑状态；以当前快捷键配置为准。
- 反馈前搜索[已有 Issues](https://github.com/aiaimimi0920/Otter/issues)，按[社区参与方式](contributing.zh-CN.md)提供版本、复现步骤和经过脱敏的截图。不要上传密钥、令牌或私人画面。
