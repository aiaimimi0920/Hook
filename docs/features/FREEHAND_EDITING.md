# 铅笔与画笔

Ctrl+E 打开主编辑栏，在铅笔按钮下拉菜单中选择“铅笔”或“画笔”。主按钮记住本次选择，点击可继续使用同一工具。

- 铅笔保持等宽笔触；画笔采用稍饱满的圆起笔、随移动速度变化的行笔和更细的收笔。鼠标慢画较饱满、快划较轻细，宽度变化经过缓动，边缘仅轻微柔化；不声称已支持数位笔原生压感。
- 两者共用颜色选择器，分别记住粗细、不透明度和平滑度。粗细范围 1–999；不透明度和平滑度范围 0–100。数字输入支持上下步进。
- 铅笔默认平滑度为 0，保持原有手绘轨迹；画笔默认粗细 16、平滑度 50。平滑度仅影响新绘制的笔迹，不会重写已有标注。
- 铅笔保留荧光开关。荧光与其他参数可以同时使用：不透明度在荧光基础强度上继续调节，平滑度照常处理轨迹，开启荧光不会隐藏任何属性。
- 单击可画圆点，拖动绘制笔迹，Shift 可约束直线。松手提交一次历史记录，Escape 或指针取消不提交未完成笔迹。
- 支持已有标注的选择、移动、旋转、缩放、撤销、重做和栅格化。

## 实现与边界

旧 `brush` 工具键继续表示铅笔，新增 `paintbrush` 工具使用独立 profile。持久化沿用 `brush` annotation，画笔以 `style.brushTip = "tapered"` 区分，旧标注没有该字段时保持等宽渲染。

平滑后的中心线存入 points，保证几何变换和保存后显示一致。铅笔保留原有 2048 点规则；画笔不再到达该阈值后删掉历史采样，也不再按变化的总长度重新分布整条线的采样点。画笔历史几何随实际绘制长度增长，按从起点固定划分的 128 点区段缓存路径；已完成区段复用原节点和路径，平滑只重算受新输入影响的尾部。SVG 和 Canvas 共用半径及连接片几何。渲染前压缩冗余采样，中心线与半径的合计近似误差不超过 0.18 个贴图像素；SVG 坐标保留两位小数，拖动期间复用预览节点。画笔移动事件按动画帧批量发布，一帧内最多保留 32 个待处理采样，拥塞时降采样且保留最新位置；松手先补齐末端再提交，取消、新笔迹和组件销毁会清掉待处理任务，避免高频原生输入积压成追赶动画。画笔只在外缘 12% 半径范围内以 4 层过渡轻微柔化，不再整圈发虚；每层一次填充整条笔触并补偿叠加透明度。采样时间仅用于草稿，提交时将无量纲粗细权重保存到 style.brushWeights；移动、旋转、缩放及重新加载不会重新计算移动速度。

本次不扩展 Loom 跨端对象编辑协议。自然画笔新增的样式字段不在旧协议内；如需使用现有跨端对象编辑，应先栅格化。

聚焦验证见 `stickerPaintbrush.test.ts` 和 `stickerPaintbrushInteraction.test.tsx`。浏览器预览不替代原生 EXE 人工验收。
