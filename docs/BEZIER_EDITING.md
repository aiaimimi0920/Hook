# 直线与贝塞尔曲线编辑

## 操作

- Ctrl+E 打开主编辑栏，在直线按钮的下拉菜单中选择“贝塞尔曲线”。
- 按下并拖动确定起点、终点；松开后创建一条初始弯曲的三次贝塞尔曲线，并自动进入选择模式。
- 白色圆点是端点或中间节点，每段有两个黄色控制点。拖动控制点独立调整曲率；拖动节点时相邻控制点跟随平移。
- 双击曲线任意非端点位置可添加节点，使用精确分段保持原曲线外形。新增白色节点可移动，其两侧黄色控制柄可以分别调整。
- 拖动起点或终点旁的 `+` 向外继续画，可反复增加曲线段；整条路径始终是同一个对象。点击 `+` 也会增加一小段。
- 右键白色节点打开“删除节点”。删除中间节点会连接相邻两段并保留两侧外端控制柄，附近形状可能改变；删除起点或终点会移除首段或末段。黄色控制柄不能单独删除，至少保留一段曲线，删除支持撤销和重做。
- 点击空白处取消选择，再点击曲线可继续编辑。选择模式下拖动曲线本身可以整体移动。
- 属性栏提供描边颜色、线宽、线型和箭头；已有直线、箭头和曲线单选后也可以修改这些属性。
- 新直线额外提供角度吸附；曲线不显示此开关。直线和曲线分别保存线宽、线型和箭头默认设置。
- 每次完整拖动只提交一次历史记录，支持撤销和重做。取消绘制或控制点拖动不提交未完成形状。

## 数据与边界

`StickerLineAnnotation.type = "bezier"`，`points` 使用兼容单段的 `3n+1` 点序列：`[起点, 控制点1, 控制点2, 节点, 控制点1, 控制点2, 节点, ...]`，最多 64 段。
`showArrowHead` 保存曲线箭头开关；`style` 沿用描边样式。保存的是控制点，不是采样折线。
平移、旋转、缩放、贴图翻转与历史快照均保留全部节点和控制柄。

无箭头时 SVG 使用 `C`，Canvas 使用 `bezierCurveTo`。带箭头时，SVG 和 Canvas
共用有界采样、轴线裁剪和末端切向箭头几何。单段采样最多 513 点，整条路径最多 4097 点，不写入持久数据。
控制柄和辅助线只属于选择层，不进入导出或栅格化结果。

原生 overlay 把 SVG 输入归一到稳定的绘制层根节点，因此控制点命中也在 pointer-down
controller 中处理，不能只依赖 SVG circle 的事件。拖动预览不改写持久 store，松开后
通过原有 persistence controller 写入 graph、history 并请求同步。

本次不扩展 Loom 的跨端协同编辑协议；曲线可本地编辑、保存和栅格化。含曲线的贴图
若需使用现有跨端对象编辑协议，应先栅格化。
